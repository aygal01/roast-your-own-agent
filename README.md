A one-line roast of my own AI agent — the agent that never says "I don't know", so it spawns three subagents, burns a million tokens, and hallucinates with total confidence.

The program is deterministic: no randomness, no clock, no network — the same roast on every run, exactly one line on stdout.

## Run it

```sh
python3 main.py
```
